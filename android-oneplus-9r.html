Making a OnePlus 9R simpler, or replacing its OS entirely

"Modify my phone OS" usually means one of three real things: simplifying stock OxygenOS's look and feel with no flashing at all, flashing an existing custom ROM (LineageOS, crDroid, ArrowOS, etc.), or building Android yourself from AOSP source. Below is the honest version of all three, for the OnePlus 9R (codename lemonadep).

Reality check first

You cannot write a brand-new operating system for a OnePlus 9R from scratch in a reasonable amount of time. Android on a real phone needs the Linux kernel with Qualcomm's board support package, OnePlus's proprietary binary blobs (Wi-Fi, modem, camera, GPU firmware), and a working bootloader/fastboot/recovery chain — none of which are things you write yourself. There are really three ways to change how the OS looks and behaves on a 9R, in order of risk:

PathWhat it isTime / difficulty
Simplify stock OxygenOSLauncher, icon pack, theming, and de-bloating, no unlock or wipe needed15–30 minutes, fully reversible
Flash a custom ROMInstall a pre-built community ROM (LineageOS, crDroid, ArrowOS, Pixel Experience) over stock OxygenOS30–60 minutes, low risk if you follow steps, wipes the phone
Build from AOSP sourceCompile Android yourself using the device's kernel/vendor tree, produce your own buildA full day of setup, 100+ GB disk, hours per build

If your goal is mainly "looks and simplicity," start with the first path below, it gets you 90% of the way there with none of the risk.

Simplify the look, no flashing required

This path changes how the phone looks and feels without touching the bootloader, recovery, or system partition. Nothing here can brick the phone, and everything is undoable from Settings.

1Switch launcher

The launcher (home screen app) controls most of what makes an Android phone feel busy or calm.

  • Niagara Launcher — a single scrollable list of apps, no grid, no icons by default. The fastest way to make a phone feel radically simpler.
  • Nova Launcher — keeps the familiar grid but gives full control over icon size, grid density, gestures, and lets you hide the app drawer clutter.
  • Lawnchair — open-source, Pixel-style launcher with a clean default look and no ads/tracking.
  • Install from Play Store, then Settings → Apps → Default apps → Home app → select it.

2Icon pack + monochrome icons

A mismatched grid of colorful icons is what makes a home screen feel cluttered. Install a minimal icon pack (e.g. "Minimal Icon Pack", "Whicons", or "Papercut") and apply it from your launcher's settings, most support this directly. On Android 13+, stock OxygenOS also has a built-in themed (monochrome) icons toggle: Settings → Wallpaper & style → Themed icons.

3Turn on OxygenOS's built-in theming

OxygenOS already ships a full theme engine, most people never open it: Settings → Customization (or Wallpaper & style) lets you set a single accent color system-wide, switch icon shape, adjust always-on-display style, and toggle dark mode on a schedule. Doing this alone removes most of the "busy" feeling without installing anything.

4Remove bloatware, without root

Preinstalled apps you can't normally uninstall can be disabled per-user via ADB, no root or bootloader unlock needed. This is reversible (factory reset restores them). 

adb shell pm list packages | grep -i oneplus   # find package names
adb shell pm uninstall --user 0 <package.name>   # removes it for your user only

Common ones people remove this way: OnePlus's own weather/community/gallery duplicates, Facebook, Netflix, and carrier apps preloaded by the retailer. Never remove core system packages like com.android.systemui or anything under com.qualcomm.

5Cut down notifications and animations

  • Settings → Notifications → go app by app and turn off anything that isn't essential.
  • Settings → About device → tap Build number 7x → Developer options → set Window/Transition/Animator scale to .5x for a snappier, less busy feel (or off entirely for max simplicity).
  • Settings → Home screen → reduce grid size and turn off the search bar / suggestion row if the launcher exposes it.
This is the path most people actually want. Everything in this section is stock-safe, reversible, and gets a materially calmer, simpler-looking phone in under half an hour. Only go further (below) if you specifically want a different Android build, not just a different look.

Before you start

This will wipe your phone and voids OnePlus's warranty stance on software. Unlocking the bootloader factory-resets the device and trips the warranty/knox-style flags some carriers check for. Back up everything (photos, messages, app data) to Google/your PC first. Do not attempt this on a phone you can't afford to lose for a day.
  • Confirm your exact model: OnePlus 9R is codename lemonadep (also seen as lemonade). ROMs are model-specific — a 9 or 9 Pro build will not work.
  • Charge to at least 60%.
  • Enable Developer Options: Settings → About phone → tap "Build number" 7 times.
  • In Developer Options, enable OEM unlocking and USB debugging.
  • On your PC, install adb and fastboot (part of Android SDK Platform Tools) and the OnePlus USB drivers if on Windows.

1Unlock the bootloader

adb reboot bootloader
fastboot flashing unlock
# confirm on-device with volume/power keys
fastboot reboot

The phone will factory reset itself. Set it up again (you can skip signing into accounts, it'll be wiped again shortly).

2Flash a custom recovery

A custom recovery (TWRP or OrangeFox for lemonadep) lets you flash ROM zips and Magisk. Download the recovery image built specifically for lemonadep from the respective project's official site or XDA thread — never a random mirror. 

adb reboot bootloader
fastboot flash recovery recovery.img
fastboot reboot recovery

Boot straight into recovery (hold Power + Volume Up as the screen goes dark) so stock Android doesn't overwrite it on next boot.

3Flash the ROM

  1. Download the ROM zip built for lemonadep (and the matching Google Apps / GApps package if the ROM doesn't include them).
  2. Copy both zips to the phone's storage via adb push or a USB cable, while in recovery or a booted stock system.
  3. In recovery: Wipe → Advanced Wipe → select Dalvik/ART Cache, Cache, System, Data (this is the actual OS wipe).
  4. Install → select the ROM zip → flash → then flash the GApps zip in the same session if used.
  5. Reboot to system. First boot can take 5–10 minutes; that's normal.

4Root access (optional)

If you want root, flash the latest Magisk zip in the same recovery session, or patch the ROM's boot.img with the Magisk app and flash the patched image with fastboot flash boot patched_boot.img.

If you actually want to build Android from source

This is the "real OS" path — compiling AOSP yourself against the 9R's device tree. It's a legitimate weekend project if you want to learn how Android is put together, not a quick task.

What you need

  • Linux machine (Ubuntu recommended) with 250GB+ free disk and 16GB+ RAM
  • The device tree, kernel source, and vendor blobs for lemonadep — LineageOS publishes these under its LineageOS GitHub org for supported devices
  • repo tool and a full day for the initial source sync (100GB+ download)

Rough sequence

# one-time host setup
sudo apt install repo git-core gnupg flex bison build-essential \
  zip curl zlib1g-dev libc6-dev-i386 libncurses5 x11proto-core-dev \
  libx11-dev lib32z1-dev

mkdir android && cd android
repo init -u https://github.com/LineageOS/android.git -b lineage-21.0
repo sync -c -j$(nproc --all)

# device-specific trees go under device/oneplus/lemonadep,
# kernel under kernel/oneplus/sm8350, vendor blobs under vendor/oneplus

source build/envsetup.sh
breakfast lemonadep
brunch lemonadep   # this compiles the OS; expect 1-4+ hours

The output .zip in out/target/product/lemonadep/ is flashed exactly like a ROM in step 3 above. This is genuinely how every custom ROM you'd download is made — you'd just be doing it yourself instead of trusting a maintainer's build.

ROM options for lemonadep

Check each project's official wiki/download page for current lemonadep support status before flashing, ROM support windows change as maintainers move on.

  • LineageOS — closest to stock Android, most actively maintained, largest device support list.
  • crDroid — LineageOS-based with more customization (Pixel-style features, extra QS tiles).
  • ArrowOS — lightweight, minimal, close to AOSP.
  • Pixel Experience — stock Google Pixel look and feel.

Community hub for lemonadep-specific build threads, kernels, and known issues: search "OnePlus 9R lemonadep" on XDA Forums.

If anything goes wrong A phone that only boots to fastboot ("bricked") is almost always recoverable via OnePlus's official MSM/Qualcomm flash tool, which restores stock firmware from a raw image. Keep a copy of the stock ROM for lemonadep downloaded before you start, just in case.
